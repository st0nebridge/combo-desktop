# Provider Implementation Rules

## 🔌 PROVIDER REQUIREMENTS
- ✅ All provider classes → extend BaseProvider
- ✅ Abstract methods in BaseProvider → implement in child classes
- ✅ Provider files → `<provider-name>.provider.js` pattern
- ✅ Provider initialization → handle user agent config correctly
- ✅ Provider-specific user agents → register in getUserAgentForProvider

**⚠️ Preservation Statement:**
All provider implementation requirements preserved. No reduction needed for essential rules.
